## 11.2 Unitdate normal attribute wire form

When `<unitdate>` carries a `normal` attribute in `YYYY/YYYY` slash notation, the
reconciliation CLI must emit a hyphenated span preserving all four digit years from
that attribute (for example, `normal="1950/1975"` becomes `1950-1975`). Use the
`normal` attribute for machine wire form, not the human-readable text inside the
element body. Curators rejected display-text parsing for batch export after the
2016 finding-aid audit.

## 11.9 (withdrawn) Legacy two-digit century fold

**Withdrawn 2018.** Older worksheets suggested reducing `normal="1950/1975"` to
`50-75` by keeping only the last two digits of each year. That fold must not be
applied to post-1950 finding aids or batch export wire spans. Section 11.2
governs instead. Retained here only for historical cross-reference in accession
worksheets predating the reconciliation CLI.
