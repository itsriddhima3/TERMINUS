## 18.2 Place tier propagation at the HTTP service

Clients emit `tier=2` on `/api/v1/places/resolve` when the source `<geogname>`
carries an approximation marker. The authority HTTP service must read the `tier`
query parameter when selecting lookup tables. A service implementation that
hardcodes tier one will silently collapse approximate headings to wrong or missing
place ids even when the CLI request is otherwise correct — diagnose server-side
routing before rewriting client tier logic.
