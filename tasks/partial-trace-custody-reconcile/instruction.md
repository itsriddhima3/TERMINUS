The custody reconciliation batch under `/app` merges partial movement traces from several observation channels per case pack. Repeat sweeps show incomplete transition ledgers: proof counters disagree with inferred rows, channel rank tie-breaks look wrong, and ledger digests drift on the same pack set. Bundled packs live under `/app/cases/`; channel ranks are in `/app/config/channel_ranks.json`.

Recompile route_pack before the sweep (`/app/docs/architecture.md`), then run `bash /app/platform/run_scenarios.sh` (invoking `/app/bin/route_pack` per pack) to write `/app/output/custody_bundle.json`. Grading rebuilds from source each verifier pass — a prebuilt binary is not sufficient. Put `failed_packs` and `failed_pack_ids` under `aggregate`, not at the bundle top level; both must read success (`failed_packs` is 0, `failed_pack_ids` empty). When a tick has an explicit handoff for a unit, sighting disagreements at that same tick must not increment `contradiction_resolved`. Each `ledger_digest` must be the full 64-character lowercase hex digest defined in `/app/docs/bundle_schema.md`, not a shortened hash. The bundle carries a 16-character lowercase hex `run_id` and a `packs` array sorted by pack id. Row-level ledger and proof field shapes are in `/app/docs/bundle_schema.md`; cross-channel movement semantics are in `/app/docs/channel_priority.md` and `/app/docs/reconcile_notes.md`. Grading may substitute packs before the sweep.
