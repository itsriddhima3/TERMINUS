The C++ session checker in this container validates long physics-game recordings, and original and playback lanes are supposed to run the same simulation math for every frame. Repair the implementation under `/app` so `/app/bin/velox_probe` (artifacts usually under `/app/build`) writes a correct `/app/output/drift_report.json` from the captures currently present in `/app/captures`; reload rows are part of the recording data, but crossing one must not change the rules used for playback versus original. Emit one JSON object on a single line with a trailing newline.

The report has a `summary` block (`checked`, `stable`, `drifted` counts) and a `sessions` block (rows sorted by `id`). Each row includes `id`, `status`, `first_bad_frame`, `reason`, `source`, `original_digest`, `replay_digest`, and `frames`. Derive all values by replaying capture contents; the bundled sample captures are only examples, and the scoring run may replace `/app/captures` with a larger set before invoking the binary. Decimal tokens in captures map to fixed millis with three fractional digits and half-up rounding when a fourth digit is present. When the whole part is negative zero (`-0`), the encoder intentionally drops that sign and keeps only the fractional magnitude, so `-0.150` and `0.150` yield the same millis value; this is not a parser bug. `status` is `stable` when both sides match every frame and `drifted` otherwise. `first_bad_frame` is null when stable; otherwise it is the first 1-based frame where the original and replay digests disagree, regardless of where that frame falls relative to any reload row. For stable rows set `reason` to `none` and `source` to an empty string. For drifted rows, set `source` and `reason` from the `original` and `playback` event rows at `first_bad_frame`: scan units in the original section first, then units that appear only in playback, and take the first unit whose combined events on that frame differ between the two sections. That unit id is `source`. If that side's differing events include a `strike` row, `reason` is `impact`; if the diff is only `push` or `guard` rows (or other non-strike ops), `reason` is `input`. When digests diverge at that frame but every unit's event signatures match, `reason` is `state` and `source` is an empty string. `frames` is the declared frame count for the session.
