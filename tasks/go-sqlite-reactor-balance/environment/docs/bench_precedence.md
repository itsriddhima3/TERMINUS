# Bench precedence

When operator notes, archived drafts, dossier annex text, and catalog memos disagree, use this order:

1. `/app/docs/catalog/` — authoritative org definitions (bootstrap, gate lattice, dwell outcome, session archive).
2. `/app/docs/storage_contract.md` — table roles and column semantics.
3. `/app/docs/move_policy.md` and `/app/docs/win_conditions.md` — operator-facing summaries that defer to catalog memos for edge cases.
4. `/app/docs/flux_ops_dossier/part_05.md` — bench policy annex restating catalog semantics for long-form review; defers to catalog memos when wording differs.
5. `/app/docs/archive/` and remaining dossier parts — non-authoritative; retained for archaeology and shift training only.

Cross-layer symptom definitions live in catalog parts 01–04. Do not infer behavior from archive prose, field bulletins, or display-only policy probes.
