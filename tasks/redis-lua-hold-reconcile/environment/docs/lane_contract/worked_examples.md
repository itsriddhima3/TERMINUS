# Worked examples

## Example 1 — solo lane

One worker deducts three units from an opening count of six. Scenario rows show matching grant and remaining totals.

## Example 2 — dual burst

Opening six, two workers each request four. Scenario rows should reconcile grants and remaining stock against the catalog cap.

## Example 3 — mixed catalog lanes

Alpha-Unit and Gamma-Tote workers run concurrently. Each lane has its own opening cap from the catalog.

## Example 4 — pipelined burst

Several commit attempts arrive in rapid succession on Beta-Crate. Remaining counts must stay consistent with grant totals.
